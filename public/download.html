Wren for Windows

The desktop app: a small notes window that floats on top of your work and expands to the full app when you need it — plus tear-off sticky notes that stay on top. An optional companion to the web app. Your notes stay on your computer.

Download for Windows

Free · Windows 10 / 11 (64-bit) · opens the latest release

First launch — Windows SmartScreen. Windows may show "Windows protected your PC." Click More info → Run anyway. This is expected for now because the app isn't code-signed yet — your notes stay on your computer.

What the desktop app is

Wren desktop runs the same app you know from the web, in its own native window:

  • Lands small, in Compact view — a narrow, always-reachable list of your notes, like a desk-side panel.
  • Expands to the full app — click Expand and the window grows into the full two-panel editor; collapse back to Compact anytime.
  • Keep-on-top pin — pin the whole window so it floats above your browser, editor, or Word while you work.
  • Floating sticky notes — pop any note out into its own small always-on-top window. Open as many as you like; they sync live with the main app.

It's an optional companion to the Wren web app — both read and write the same plain .md files in the folder you choose. Nothing is uploaded; your notes never leave your computer.

System requirements

  • Windows 10 or 11, 64-bit (x64).
  • About 15 MB of disk space. No account, no login.

Install

  1. Click Download for Windows above and run the .exe installer.
  2. If SmartScreen appears, choose More info → Run anyway (see the note above).
  3. Launch Wren, then choose the folder where your notes live (or point it at the same folder you already use with the web app).

Updates

Updates are manual for now: when a new version ships, come back to this page and download the latest installer — it installs over the old one and your notes are untouched. (Automatic updates will come once the app is code-signed.)
